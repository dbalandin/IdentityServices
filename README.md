# identity-service

Общий сервис аутентификации экосистемы на .NET 10. Владелец — команда облакотех; порядок внедрения:

- внедрение
- расширение схемы пользователя. добавление дополнительнх свойств для пользователя
- расширение методов аутентификацию (passwordless)
- подключение аутентификации к тестовому сервису
- портал администратора пользователей

## Конфигурация

keyclock использует PostgreSQL.  
Данные для поключения храняться в `.env` проекта  
Сервис маппится на порт 127.0.0.1:10020  
В дальнешем сервер публикуется в Интернет через nginx reverse-proxy
