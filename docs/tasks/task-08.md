## Цель

Автоматическая проверка ключевых инвариантов фазы 1: контракт JWT и org-изоляция портала. Тесты гоняются против живого окружения (compose + init).

## Что сделать

`tests/` — интеграционные автотесты (стек — на усмотрение исполнителя, .NET xUnit логичен рядом с demo-api/порталом):

1. **Контракт JWT**:
   - получить токен seeded-пользователя (direct access grants, dev-only);
   - сверить состав клеймов с эталоном `docs/contracts/jwt-claims.md` (organization, groups, realm_access.roles, scope, email/preferred_username);
   - проверить подпись (JWKS realm).
2. **Орг-изоляция портала**:
   - admin org A запрашивает пользователей org B → 403/404;
   - admin org A управляет пользователями org A → 200.
3. **Безопасность (из плана §7)**:
   - 5 неверных паролей подряд → блокировка/нарастающее ожидание;
   - неверный логин и несуществующий логин — неотличимы (одинаковая ошибка/тайминг в пределах разумного);
   - forgot-password не раскрывает существование username.
4. Запуск тестов описать командой (пополнить README / AGENTS «Сборка и тесты» — синхронизация с task-09).
5. Зафиксировать изменение в `docs/CHANGELOG.md`.
